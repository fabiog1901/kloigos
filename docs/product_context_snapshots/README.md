# Product Context Snapshots

Product Context Snapshots provide a concise, canonical description of **what Kloigos is, how it works, and how it should be positioned**.

They capture the current product model, architectural principles, terminology, major capabilities, and design invariants so that developers, Codex, documentation authors, and other contributors share the same understanding of the system.

Snapshots describe the **intended product as a coherent whole**, regardless of whether individual capabilities are still being implemented. Detailed implementation specifications remain in the repository and GitHub issues; the snapshot provides the higher-level context needed to interpret them consistently.

When documentation or implementation conflicts with a Product Context Snapshot, the conflict should be identified and resolved explicitly rather than silently choosing one interpretation.
